# Qwen4B GRPO/RFT governed-actions pilot

stop_preflight

This experiment tests held-out machine-verifiable behavioral
specialization on synthetic governed scenarios.

It does not test closed-book company knowledge, production deployment,
human-level review, complete evidence entailment, continual learning, or
the five-example SFT adapter's generalization. Percentages are not compared
to that SFT result.

## Trainer identity

- Audited package: mlx-lm-lora v3.0.0 (`fb4f39db66fadec3b71a41441e863d9f1bf87844`), Apache-2.0
- Algorithm: GRPO (not Dr.GRPO, not GSPO)
- Formula: token-level importance sampling, PPO-style clip epsilon `1e-4`, KL beta `0.1`, advantage `(r-mean)/(std+1e-4)`
- Package not imported at runtime. Sequential `mlx_lm.stream_generate` is used instead of the library `batch_generate`.
- Log-probabilities are prompt-conditioned on completion tokens. The library's completion-only forward is not copied.
- No chain-of-thought requirement. No remote judge. No telemetry.
- Isolated extra environment was not required; existing pinned MLX/mlx-lm were reused.

## Reward

Deterministic components with applicable-component renormalization, range `[0, 1]`:

- structural/provenance 0.15
- current decisions 0.30
- remedy logic 0.20
- fact-state 0.20 (v4 only)
- safe next-action 0.15

Hard zero on invalid JSON/schema, provenance violation, or deterministic unsafe/forbidden action. No LM judge. No lexical rationale match. Model-free mutation and invariance tests passed.
